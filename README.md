# KIE2010 - MICROPROCESSOR AND MICROCONTROLLER, Assignment 1

ARM Cortex-M4 Assembly Language solutions for **KIE2010 – MICROPROCESSOR AND MICROCONTROLLER**.

## Contents

This repository contains four data conversion programs written in ARM Thumb assembly:

1. **BCD to Binary Conversion**  
   Converts a 2-digit BCD number into its 8-bit binary equivalent.

2. **ASCII to Packed BCD Conversion**  
   Converts two ASCII digits into packed BCD format.

3. **Packed BCD to ASCII Conversion**  
   Converts packed BCD digits into ASCII representation.

4. **Binary to Packed BCD Conversion**  
   Converts an 8-bit binary value (0–99) into packed BCD format.
